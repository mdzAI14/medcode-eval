# medcode-eval

A coder-authored test set that measures how large language models handle
ICD-10-CM diagnosis coding, plus a deterministic ICD-10-CM rules checker
that is one of the tested conditions.

- Status: in development
- Code set: ICD-10-CM FY2027
- Author: mdzAI14

Code facts come only from the reference files in `refdata/`. Gold codes and
citations under `data/gold/` are entered by the author, never generated.
Code is MIT-licensed (`LICENSE`); test data is CC BY 4.0 (`LICENSE-DATA`).
