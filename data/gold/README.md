# data/gold

Gold codes and citations in this folder are drafted with AI
assistance and verified by the author against the code set and the
Official Guidelines tracked under refdata/. Each file's `method`
and `method_detail` fields record how it was produced. The author
places these files. No automated task creates or changes their
content.

A mechanical transform of these files (reformat, sort, schema change) is
allowed only when it is shown to leave every code and citation unchanged.
