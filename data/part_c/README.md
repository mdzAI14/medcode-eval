# Part C: when not to code

Code set: ICD-10-CM FY2027 (October 1, 2026 release).

Part C is part of release v0.2.0. Its 30 cases and their gold were
settled before the reported runs were made. The results are in
results/RESULTS.md, sections S9 to S13.

Each of the 25 gap cases leaves out, on purpose, one thing that a more
specific code would need. The gold codes are what can be reported
from the note as written. In each of the 5 counter-cases the note does
support the specific code, so holding back is the error. The layout
and the fields are described in docs/part_c_schema.md.
