# Part C: when not to code (in development)

Code set: ICD-10-CM FY2027 (October 1, 2026 release).

Part C is in development and is not part of release v0.1.0. No result
has been reported from it. Until release v0.2.0 is tagged, the files
here may change.

Each Part C case leaves out, on purpose, one thing that a more
specific code would need. The gold codes are what can be reported
from the note as written. The layout and the fields are described in
docs/part_c_schema.md.
